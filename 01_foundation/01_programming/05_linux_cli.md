# 🐧 Linux Command Line Fundamentals

> Dedicated Study Guide for Task 5 of Module 01: Programming for AI

## 🎯 Learning Objectives
- Navigate filesystem, manage files/directories, inspect permissions, and write shell scripts.
- Manage Python virtual environments (`venv`, `conda`, `uv`) and environment variables (`.env`).
- Execute remote GPU server tasks via SSH and process background jobs (`tmux`, `nohup`).

## 📚 Free Recommended Resources
- [Linux Command Line Basics – Coursera (UC Davis)](https://www.coursera.org/learn/linux-command-line) — **Free to Audit**
- [The Linux Command Line (Book by William Shotts)](https://linuxcommand.org/tlcl.php) — **Free PDF**

## 🔑 Key Commands & Concepts
1. **File Operations**: `ls -la`, `cd`, `mkdir`, `cp`, `mv`, `rm -rf`, `grep`, `find`, `cat`, `less`.
2. **Environment & Virtual Environments**: `python3 -m venv .venv`, `source .venv/bin/activate`, `export VAR=val`.
3. **Process & Remote Management**: `ps aux`, `kill -9`, `ssh user@host`, `scp`.
