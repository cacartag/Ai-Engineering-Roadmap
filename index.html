🌐 Access Your Dashboard Everywhere

Because this dashboard is built right into your git repository, you can publish it to GitHub Pages for free in 2 steps:


  1. Push this repository to your GitHub account:
    git add . && git commit -m "Add interactive roadmap dashboard" && git push
  2. In your GitHub Repo: Go to Settings → Pages → Set Source to Deploy from a branch (Main branch / root).

✨ Once enabled, your progress dashboard will be live at https://<your-username>.github.io/Ai-Engineering-Roadmap/ on any phone, tablet, or laptop!


💡 Bonus: Use the Export/Import JSON buttons on any device to keep your progress completely in sync!
